# outlive.diy feature map

`../features.json` is generated by `featuremap` and never edited by hand. The
files here hold the recipes. Each one declares the ids it covers in a
`<!-- covers: -->` line, and `featuremap check` fails when an id has no recipe or
a recipe covers an id that no longer exists.

## Preconditions

The app launched per `../SKILL.md` and Playwright installed at `$PW`. Every recipe
starts from cleared storage (the driver does it). A plan lives only in the
browser, so there is nothing to seed and nothing to clean up server-side.

Never drive Claude with a real key without the owner's say-so: it spends money on
their Anthropic account. An invalid key proves the whole request path for free.

## Proof rules

- Drive the path a user takes. Mocks count only at a boundary production also has
  (Anthropic's API), never around the code being checked.
- A recipe lists every entry point. Proving one convenient entry point does not
  prove the others.
- An unreachable entry point is reported with its missing precondition. It is not
  counted as verified.
- Nothing may request anything but the page's own assets, except a Claude question.
  The driver's outside-requests line is part of every proof.

## Areas

- [shell](shell.md): the landing page, the app document, the terms, the palette, the offline copy, the no-network check.
- [describe](describe.md): the builder and the seven design steps.
- [diagnosis](diagnosis.md): overview, findings with their fixes, the map.
- [documents](documents.md): build runbook, recovery routes, successor letter, and printing them.
- [more](more.md): compare, the plan file page, the rules page.
- [claude](claude.md): asking Claude with a key the reader supplies.
- [engine](engine.md): the `@outlive/core` package.
- [site-metadata](site-metadata.md): icons, manifest, share image, robots, sitemap.

## Entry contract

Each area file has: an H1, a one-line summary, a `<!-- covers: ids -->` line, then
exactly these sections: `## Sub-features`, `## How to reach it`, `## How to check
it`, `## Gotchas`. Keep it short enough to run without reading source. Split a
file once a section needs its own preconditions.
